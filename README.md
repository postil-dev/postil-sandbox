# Postil sandbox

Small public fixture for exercising [Postil](https://postil.dev) pull-request reviews. The repository is test infrastructure, not an example application.

For local use, follow the [Postil CLI guide](https://github.com/postil-dev/postil-cli). For GitHub Actions, use the [Postil Action](https://github.com/postil-dev/postil-action).
