# Postil sandbox

Small public fixture for exercising [Postil](https://postil.dev) pull-request reviews. The repository is test infrastructure, not an example application.

See [`postil-cli`](https://github.com/postil-dev/postil-cli) to run the reviewer locally or [`postil-action`](https://github.com/postil-dev/postil-action) to add it to GitHub Actions.
