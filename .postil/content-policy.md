# Content policy

Prose merged into this repository (docs, comments, PR descriptions) must
hold to these rules:

1. No fabricated or unverifiable claims: user counts, performance numbers,
   or adoption statements must be real and checkable.
2. No AI-authorship residue: no assistant self-references, apologies, or
   conversational artifacts left in committed text.
3. No placeholder text (lorem ipsum, TODO-filled prose) in files presented
   as finished documentation.
